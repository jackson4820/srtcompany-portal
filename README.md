# Install
server:  npm i express mongoose bcryptjs jsonwebtoken cors helmet express-rate-limit dotenv multer nodemailer
client: cd
Admin banane ke liye: cd server && node scripts/seedAdmin.js
Client .env: VITE_API_BASE_URL=http://localhost:5000/api/v1  (ya vite proxy: vite.config.example.js)
Tailwind + src/index.css (@tailwind directives) aapke project me pehle se hona chahiye.
